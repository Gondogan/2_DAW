## 📂 Estructura del Repositorio

Este entorno está optimizado para funcionar simultáneamente como **entorno de desarrollo** y como **bóveda de conocimiento en Obsidian**. 

El sistema ignora automáticamente carpetas pesadas como `node_modules` para mantener el repositorio limpio y el gestor de notas rápido. Cada asignatura (DWEC, DWES, DIW...) sigue esta arquitectura modular:

```text
📁 Nombre_Asignatura/
├── 📘 Apuntes/           # Teoría, resúmenes y documentación en Markdown
├── 📝 ejercicios_clase/  # Prácticas diarias y snippets de código
├── 🚀 Proyectos/         # Proyectos completos y entregables (aislados de Obsidian)
└── 📦 Recursos/          # PDFs, imágenes, assets y bibliografía
